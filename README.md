# AgentForge Web3

AgentForge is a cinematic product interface for controlled AI agents that help Web3 teams turn fragmented operational signals into inspectable workflows.

## Product idea
Signal → Reason → Act → Report, with human approval gates, scoped permissions and traceable runs.

## Stack
Next.js, React, TypeScript, Framer Motion, CSS.

## Principles
- No fabricated customers, metrics or integrations.
- Human approval for sensitive actions.
- Explain the workflow before claiming autonomy.
- Responsive and accessible by default.

## Run locally
npm install
npm run dev
